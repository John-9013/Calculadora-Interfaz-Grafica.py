# Calculadora-Interfaz-Grafica.py

Se añadió una rama `add/power-functions-comments` con mejoras al analizador (lexer + parser) usado por la interfaz gráfica.

Cambios principales:
- Soporte para `**` (potencia), llamadas a funciones matemáticas seguras y comentarios de línea.

Instrucciones rápidas:
1. Cambia a la rama `add/power-functions-comments` o abre el PR para revisar los cambios.
2. Instala dependencias: `pip install ply`
3. Ejecuta la interfaz gráfica (el archivo principal) y prueba las expresiones del archivo `examples/USAGE.md`.

Si quieres, puedo abrir el Pull Request ahora con esta rama. Si deseas revisar o modificar la lista de funciones permitidas o el operador de potencia, dime y ajusto antes de abrir el PR.
